## Section 1 — Programming Logic

1. {What is a variable?} : {A variable stores a value that a program can use or change.}
    
2. {What is a data type?} : {A data type defines what kind of value a variable contains, such as an integer, string, Boolean, or list.}
    
3. {What is a Boolean?} : {A Boolean is a value that can be either true or false.}
    
4. {What is a conditional statement?} : {A conditional statement runs different code depending on whether a condition is true or false.}
    
5. {What is a loop?} : {A loop repeatedly executes code until a sequence is finished or a condition changes.}
    
6. {What is a function?} : {A function is a reusable block of code that performs a specific task.}
    
7. {What is a parameter?} : {A parameter is a value that a function receives as input.}
    
8. {What is a return value?} : {A return value is the result that a function sends back to the code that called it.}
    
9. {What is an expression?} : {An expression combines values, variables, and operators to produce a result.}
    
10. {What is an operator?} : {An operator performs an operation such as addition, comparison, assignment, or logical evaluation.}
    
11. {What does == mean?} : {The == operator checks whether two values are equal.}
    
12. {What is the difference between = and ==?} : {The = operator assigns a value, while == compares two values.}
    
13. {What do and, or, and not do?} : {They combine or reverse Boolean conditions.}
    
14. {What is program flow?} : {Program flow is the order in which instructions are executed.}
    
15. {Why is understanding program flow important?} : {It helps you predict what the program will do and locate where incorrect behavior starts.}
    

## Section 2 — Data Structures

16. {What is a list?} : {A list stores multiple values in an ordered collection.}
    
17. {What is an index?} : {An index identifies the position of an element inside an ordered collection.}
    
18. {What is a dictionary?} : {A dictionary stores values using key-value pairs.}
    
19. {What is a key-value pair?} : {A key identifies a value stored inside a dictionary or similar data structure.}
    
20. {What is a set?} : {A set stores unique values without duplicates.}
    
21. {What is a tuple?} : {A tuple is an ordered collection that is normally not modified after creation.}
    
22. {When should you use a list instead of a single variable?} : {You should use a list when you need to store and process multiple related values.}
    
23. {What is nested data?} : {Nested data occurs when one data structure contains another data structure.}
    
24. {Why is understanding nested data important?} : {APIs and real applications frequently use lists containing dictionaries or other nested structures.}
    
25. {What does iterating over a list mean?} : {Iterating means processing each element of the list one at a time.}
    

## Section 3 — Code Reading

26. {What should you identify first when reading unfamiliar code?} : {You should identify the inputs, outputs, major functions, and overall flow of the program.}
    
27. {How do you understand a function you did not write?} : {Check its parameters, internal operations, return value, and where it is called.}
    
28. {What does calling a function mean?} : {Calling a function tells the program to execute that function.}
    
29. {Why should you trace variable values while reading code?} : {Tracing values helps you understand how information changes as the program executes.}
    
30. {What is a side effect?} : {A side effect occurs when a function changes something outside itself, such as a file, database, or global variable.}
    
31. {What is a code dependency?} : {A dependency is code or a library that another part of the program requires to work.}
    
32. {What is importing code?} : {Importing allows one file to use functions, classes, or variables defined somewhere else.}
    
33. {Why is reading code more important than memorizing syntax for vibe coding?} : {AI can generate syntax, but you must understand whether the generated code logically makes sense.}
    

## Section 4 — Debugging

34. {What is a bug?} : {A bug is a defect that causes software to behave incorrectly.}
    
35. {What is debugging?} : {Debugging is the process of locating the cause of a problem and correcting it.}
    
36. {What is a syntax error?} : {A syntax error happens when code does not follow the grammatical rules of the programming language.}
    
37. {What is a runtime error?} : {A runtime error occurs while the program is executing.}
    
38. {What is a logic error?} : {A logic error occurs when the program runs but produces the wrong result.}
    
39. {What is an exception?} : {An exception is an error or unusual condition generated while a program is running.}
    
40. {What is a stack trace?} : {A stack trace shows the sequence of function calls that led to an error.}
    
41. {What part of an error message should you inspect first?} : {You should inspect the error type, message, file name, and line number.}
    
42. {Why should you reproduce a bug?} : {A reproducible bug is much easier to investigate and verify after fixing.}
    
43. {What does isolating a bug mean?} : {Isolating a bug means narrowing the problem down to the smallest relevant section of code.}
    
44. {Why should you change one thing at a time when debugging?} : {Changing one thing at a time helps identify which modification actually affected the problem.}
    
45. {Why are print statements useful for debugging?} : {They let you inspect variable values and determine what the program is doing internally.}
    
46. {What is logging?} : {Logging records information about what a program is doing during execution.}
    
47. {What is an edge case?} : {An edge case is an unusual input or situation that may cause unexpected behavior.}
    
48. {Why should you test empty input?} : {Empty input can expose assumptions that required data will always exist.}
    

## Section 5 — Files and Computer Knowledge

49. {What is a file path?} : {A file path tells the computer where a file or folder is located.}
    
50. {What is an absolute path?} : {An absolute path describes the complete location of a file starting from the root of the file system.}
    
51. {What is a relative path?} : {A relative path describes a file location relative to the program's current directory.}
    
52. {What is the current working directory?} : {It is the directory from which the program or terminal is currently operating.}
    
53. {What is a file extension?} : {A file extension indicates a file's format, such as .py, .txt, .csv, or .json.}
    
54. {What does reading a file mean?} : {Reading a file means loading its stored contents into a program.}
    
55. {What does writing to a file mean?} : {Writing means storing or modifying information inside a file.}
    
56. {What is a directory?} : {A directory is a folder used to organize files and other directories.}
    
57. {What does deleting a file do?} : {Deleting removes the file from the file system and may cause permanent data loss.}
    

## Section 6 — Terminal Skills

58. {Why should a coder know how to use a terminal?} : {The terminal allows you to run programs, navigate folders, install packages, and diagnose problems efficiently.}
    
59. {What does cd do?} : {The cd command changes the current directory.}
    
60. {What does ls or dir do?} : {It displays the contents of the current directory.}
    
61. {What does pwd do?} : {It displays the current working directory.}
    
62. {How do you run a Python file from a terminal?} : {You normally run it with a command such as python filename.py.}
    
63. {Why is terminal output important?} : {Terminal output often contains program results, warnings, and error information needed for debugging.}
    

## Section 7 — Python Skills

64. {Why is Python useful for a beginner vibe coder?} : {Python has simple syntax and is widely used for automation, data processing, scripting, APIs, and AI applications.}
    
65. {What is indentation in Python?} : {Indentation determines which statements belong to the same block of code.}
    
66. {What does if do in Python?} : {An if statement executes code when a specified condition is true.}
    
67. {What does for do in Python?} : {A for loop processes each item in an iterable such as a list.}
    
68. {What does while do in Python?} : {A while loop repeatedly executes code while a condition remains true.}
    
69. {What does def mean in Python?} : {The def keyword defines a function.}
    
70. {What does import mean in Python?} : {Import makes code from another module or library available to your program.}
    
71. {What does None mean in Python?} : {None represents the absence of a value.}
    
72. {What is a Python class?} : {A class defines a structure for creating objects that contain related data and behavior.}
    
73. {What is an object?} : {An object is an instance of a class containing its own data and accessible methods.}
    
74. {What is a method?} : {A method is a function associated with an object or class.}
    

## Section 8 — Data Processing

75. {What is CSV data?} : {CSV stores table-like data as rows and columns in a text file.}
    
76. {What is JSON data?} : {JSON stores structured information using objects, arrays, keys, and values.}
    
77. {Why should a coder understand JSON?} : {JSON is commonly used by APIs, configuration files, and applications to exchange structured data.}
    
78. {What is data parsing?} : {Parsing converts raw data into a structure that a program can understand and process.}
    
79. {What is data cleaning?} : {Data cleaning detects and corrects missing, inconsistent, duplicate, or incorrectly formatted data.}
    
80. {What is filtering data?} : {Filtering selects only records that satisfy specified conditions.}
    
81. {What is sorting data?} : {Sorting arranges data according to a chosen property such as name, date, or numerical value.}
    
82. {What is type conversion?} : {Type conversion changes a value from one data type into another.}
    
83. {Why does type conversion cause many bugs?} : {Programs may treat visually similar values differently, such as the string "10" and the integer 10.}
    

## Section 9 — Functions and Code Organization

84. {Why should you avoid writing everything in one large function?} : {Smaller functions make code easier to understand, test, reuse, and debug.}
    
85. {What is code reuse?} : {Code reuse means using the same function or component instead of rewriting equivalent logic repeatedly.}
    
86. {What is duplicate code?} : {Duplicate code is the same or very similar logic repeated in several places.}
    
87. {Why is duplicate code problematic?} : {It makes maintenance harder because the same logic may need to be fixed in multiple places.}
    
88. {What is refactoring?} : {Refactoring reorganizes code to improve its structure without changing its intended behavior.}
    
89. {What is separation of concerns?} : {Separation of concerns means giving different parts of a program distinct responsibilities.}
    
90. {Why are meaningful variable names important?} : {Meaningful names make code easier for humans and AI to understand and modify.}
    

## Section 10 — Git

91. {What problem does Git solve?} : {Git records changes to code so that versions can be compared, restored, and developed safely.}
    
92. {What is a repository?} : {A repository is a project whose files and change history are tracked by Git.}
    
93. {What is a commit?} : {A commit is a recorded snapshot of project changes.}
    
94. {Why should you commit before letting AI make a large change?} : {A commit gives you a safe version to return to if the AI-generated changes break the project.}
    
95. {What does git status show?} : {Git status shows which project files have been modified, added, deleted, or staged.}
    
96. {What does git diff show?} : {Git diff shows exactly what has changed between versions of your code.}
    
97. {What is a Git branch?} : {A branch provides a separate line of development where changes can be tested independently.}
    

## Section 11 — Libraries and Dependencies

98. {What is a library?} : {A library is reusable code written by others that provides functionality your program can use.}
    
99. {What is a dependency?} : {A dependency is an external package or library that your project requires.}
    
100. {What is pip?} : {Pip is a package manager commonly used to install Python libraries.}
    
101. {Why can installing the wrong package version break code?} : {Different versions may contain different functions, behavior, or compatibility requirements.}
    
102. {What is a virtual environment?} : {A virtual environment isolates one Python project's dependencies from other projects.}
    
103. {Why should you understand dependencies when using AI-generated code?} : {AI may introduce unnecessary, outdated, or incompatible packages that cause errors.}
    

## Section 12 — Practical Vibe-Coding Skills

104. {What is problem decomposition?} : {Problem decomposition means breaking a large programming task into smaller solvable parts.}
    
105. {Why should you give AI one clear coding task at a time?} : {Smaller tasks reduce mistakes and make generated changes easier to understand and test.}
    
106. {What information should a good coding prompt contain?} : {It should describe the current code, desired behavior, inputs, outputs, constraints, and relevant errors.}
    
107. {What should you provide AI when code fails?} : {Provide the relevant code, exact error message, expected result, actual result, and reproduction steps.}
    
108. {Why should you inspect AI-generated changes before accepting them?} : {The AI may fix one problem while unintentionally creating another.}
    
109. {Why should you understand the code even if AI wrote it?} : {You need enough understanding to debug, modify, test, and judge whether the generated solution is correct.}
    
110. {What is the most valuable skill in vibe coding?} : {The most valuable skill is turning a problem into clear technical steps and debugging the resulting implementation when it fails.}
