## Section 1 — Computer & Operating System Basics

1. {What is a file system?} : {A file system organizes files and folders so that programs and users can store, locate, and manage data.}
    
2. {What is a file path?} : {A file path specifies the exact location of a file or folder on a computer.}
    
3. {What is the difference between an absolute path and a relative path?} : {An absolute path gives the complete location of a file, while a relative path describes its location from the current directory.}
    
4. {What is a file extension?} : {A file extension such as .py, .json, or .csv indicates the format or intended use of a file.}
    
5. {What is a process?} : {A process is a running instance of a program that uses system resources such as memory and CPU time.}
    
6. {What is RAM?} : {RAM is temporary working memory that stores data and programs currently being used by the computer.}
    
7. {What is an environment variable?} : {An environment variable stores configuration information such as API keys, paths, or application settings outside the source code.}
    
8. {Why should API keys not be written directly into source code?} : {API keys should be stored securely because exposing them in source code can allow unauthorized people to use your accounts or services.}
    

## Section 2 — Terminal & Command Line

9. {Why is command-line knowledge useful for vibe coding?} : {The command line lets you run programs, install packages, navigate projects, inspect files, and diagnose problems efficiently.}
    
10. {What does the cd command do?} : {The cd command changes the terminal's current working directory.}
    
11. {What does pwd do?} : {The pwd command shows the full path of the directory in which you are currently working.}
    
12. {What does ls or dir do?} : {The ls or dir command displays the files and folders contained in a directory.}
    
13. {What is a terminal command?} : {A terminal command is a text instruction sent directly to the operating system or another command-line program.}
    
14. {What is the current working directory?} : {The current working directory is the folder in which terminal commands are currently being executed.}
    
15. {Why should you read terminal error messages?} : {Terminal error messages often reveal exactly which file, dependency, command, or configuration caused a program to fail.}
    

## Section 3 — Programming Fundamentals

16. {What is a variable?} : {A variable is a named location used to store a value that a program can access or modify.}
    
17. {What is a data type?} : {A data type defines what kind of value something represents, such as a number, string, Boolean, list, or object.}
    
18. {What is a function?} : {A function is a reusable block of code designed to perform a specific task.}
    
19. {What is a function parameter?} : {A parameter is an input that allows a function to operate on different values.}
    
20. {What is a return value?} : {A return value is the result that a function sends back after completing its work.}
    
21. {What is a conditional statement?} : {A conditional statement makes a program perform different actions depending on whether specified conditions are true or false.}
    
22. {What is a loop?} : {A loop repeatedly executes a block of code until a condition is reached or a collection has been processed.}
    
23. {What is an array or list?} : {An array or list stores multiple values in an ordered collection.}
    
24. {What is an object or dictionary?} : {An object or dictionary stores information as related key-value pairs.}
    
25. {What is a Boolean value?} : {A Boolean value represents one of two logical states, usually true or false.}
    
26. {What is scope in programming?} : {Scope determines where in a program a variable or function can be accessed.}
    
27. {What is a module?} : {A module is a file or package containing reusable functions, classes, or other code that can be imported into another program.}
    
28. {Why should a large program be divided into smaller functions?} : {Dividing a program into smaller functions makes the code easier to understand, test, debug, and modify.}
    

## Section 4 — Reading AI-Generated Code

29. {What should you check first when AI generates code?} : {You should first understand what each major section of the code is supposed to do before running or modifying it.}
    
30. {Why should you not blindly copy AI-generated code?} : {AI-generated code may contain incorrect logic, nonexistent libraries, security problems, or assumptions that do not match your project.}
    
31. {What should you do when you do not understand a line of generated code?} : {You should ask the AI to explain the line, its inputs, its output, and why it is necessary.}
    
32. {Why is understanding program flow important?} : {Understanding program flow lets you follow how data moves through functions and identify where incorrect behavior begins.}
    
33. {What is pseudocode?} : {Pseudocode describes program logic in simple human-readable steps before it is implemented in a programming language.}
    
34. {Why is pseudocode useful for vibe coding?} : {Pseudocode helps you verify the logic of a solution before asking AI to generate detailed code.}
    

## Section 5 — Debugging

35. {What is debugging?} : {Debugging is the systematic process of finding, understanding, and correcting errors in software.}
    
36. {What is a syntax error?} : {A syntax error occurs when code violates the grammatical rules of the programming language.}
    
37. {What is a runtime error?} : {A runtime error occurs while a program is executing even though the code was syntactically valid.}
    
38. {What is a logic error?} : {A logic error occurs when a program runs successfully but produces an incorrect result.}
    
39. {What information should you give AI when asking it to fix a bug?} : {You should provide the relevant code, complete error message, expected behavior, actual behavior, and steps that reproduce the problem.}
    
40. {Why are print statements or logs useful?} : {Print statements and logs reveal intermediate values and program states so that you can locate where behavior becomes incorrect.}
    
41. {What does reproducing a bug mean?} : {Reproducing a bug means finding a reliable sequence of actions that causes the same problem repeatedly.}
    
42. {Why should you change one thing at a time while debugging?} : {Changing one thing at a time makes it easier to determine which modification actually fixed or caused the problem.}
    
43. {What is a stack trace?} : {A stack trace shows the sequence of function calls that led to an error and often identifies the problematic file and line.}
    
44. {What is an edge case?} : {An edge case is an unusual or extreme input or situation that can reveal problems not visible during normal use.}
    

## Section 6 — Git & Version Control

45. {What is Git?} : {Git is a version-control system that records changes to project files and allows previous versions to be recovered.}
    
46. {What is a Git repository?} : {A Git repository is a project directory whose file changes are tracked by Git.}
    
47. {What is a commit?} : {A commit is a saved snapshot of selected changes in a Git repository.}
    
48. {Why should you commit frequently when vibe coding?} : {Frequent commits let you restore a working version when AI-generated modifications unexpectedly break the project.}
    
49. {What is a branch in Git?} : {A branch is an independent line of development that allows changes to be tested without immediately affecting the main version.}
    
50. {What does git diff show?} : {Git diff shows the differences between versions of files so that you can inspect exactly what has changed.}
    
51. {What does git status show?} : {Git status shows which files have been modified, added, deleted, staged, or left untracked.}
    
52. {What is GitHub?} : {GitHub is an online platform for storing Git repositories, collaborating on code, and showcasing software projects.}
    

## Section 7 — Packages & Dependencies

53. {What is a software dependency?} : {A dependency is an external library or package that a program relies on to perform certain functions.}
    
54. {What is a package manager?} : {A package manager such as pip or npm installs, updates, and manages software dependencies.}
    
55. {Why are dependency versions important?} : {Different dependency versions may behave differently and can make previously working code fail.}
    
56. {What is a virtual environment in Python?} : {A virtual environment isolates a project's Python packages so that they do not conflict with packages used by other projects.}
    
57. {What is requirements.txt?} : {A requirements.txt file records the Python packages needed to reproduce a project's software environment.}
    
58. {What is package.json?} : {A package.json file describes a JavaScript project and records its dependencies, scripts, and project configuration.}
    

## Section 8 — Web Development Basics

59. {What is frontend development?} : {Frontend development creates the part of an application that users see and interact with in their browser.}
    
60. {What is backend development?} : {Backend development handles server-side logic, databases, authentication, and communication between services.}
    
61. {What does HTML do?} : {HTML defines the structure and content of a webpage.}
    
62. {What does CSS do?} : {CSS controls the appearance, layout, spacing, and visual presentation of a webpage.}
    
63. {What does JavaScript do in a webpage?} : {JavaScript adds logic, interactivity, dynamic content, and communication with servers to webpages.}
    
64. {What is a server?} : {A server is a computer or program that receives requests and provides data or services to other programs called clients.}
    
65. {What is a client?} : {A client is a program such as a web browser that requests information or services from a server.}
    
66. {What is localhost?} : {Localhost refers to your own computer and is commonly used to run and test applications locally before deployment.}
    
67. {What is a port?} : {A port is a numbered communication endpoint that allows different network services on the same computer to receive connections.}
    
68. {What is a URL?} : {A URL identifies the location of a resource or service on a network such as the internet.}
    

## Section 9 — APIs

69. {What is an API?} : {An API is a defined interface that allows one software system to request data or functionality from another system.}
    
70. {What is an API endpoint?} : {An API endpoint is a specific address where a client can request a particular resource or action.}
    
71. {What is an HTTP request?} : {An HTTP request is a message sent by a client to a web server asking it to retrieve, create, modify, or delete information.}
    
72. {What does a GET request usually do?} : {A GET request normally retrieves information from a server without changing the stored data.}
    
73. {What does a POST request usually do?} : {A POST request normally sends data to a server to create something or trigger an operation.}
    
74. {What does an HTTP status code indicate?} : {An HTTP status code indicates whether a web request succeeded, failed, or requires some additional action.}
    
75. {What does HTTP 404 mean?} : {HTTP 404 means that the requested resource could not be found on the server.}
    
76. {What does HTTP 500 mean?} : {HTTP 500 indicates that the server encountered an internal error while processing the request.}
    
77. {What is API authentication?} : {API authentication verifies that a user or application has permission to access an API.}
    

## Section 10 — Data & JSON

78. {What is JSON?} : {JSON is a text-based format for representing structured data using objects, arrays, keys, and values.}
    
79. {Why should a vibe coder understand JSON?} : {JSON is widely used to exchange data between APIs, web applications, configuration files, and AI services.}
    
80. {What is CSV?} : {CSV is a simple text format that stores table-like data as rows of values separated by delimiters such as commas.}
    
81. {What is data validation?} : {Data validation checks whether incoming data has the expected type, format, range, and required values before it is processed.}
    
82. {Why should user input always be validated?} : {User input should be validated because unexpected or malicious values can cause incorrect behavior, crashes, or security vulnerabilities.}
    

## Section 11 — Databases & SQL

83. {What is a database?} : {A database is an organized system for storing, retrieving, modifying, and managing persistent information.}
    
84. {What is SQL?} : {SQL is a language used to query and manipulate information stored in relational databases.}
    
85. {What is a database table?} : {A database table stores related information in rows and columns.}
    
86. {What is a primary key?} : {A primary key uniquely identifies each record in a database table.}
    
87. {What is a foreign key?} : {A foreign key connects a record in one database table to a related record in another table.}
    
88. {What does SELECT do in SQL?} : {SELECT retrieves specified information from one or more database tables.}
    
89. {What does INSERT do in SQL?} : {INSERT adds new records to a database table.}
    
90. {What does UPDATE do in SQL?} : {UPDATE modifies existing records in a database table.}
    
91. {What does DELETE do in SQL?} : {DELETE removes selected records from a database table.}
    
92. {Why should DELETE operations be handled carefully?} : {Incorrect DELETE operations can permanently remove large amounts of important data if their conditions are wrong.}
    

## Section 12 — Testing

93. {What is software testing?} : {Software testing checks whether an application behaves correctly under expected and unexpected conditions.}
    
94. {What is a test case?} : {A test case defines a particular input or situation together with the expected result.}
    
95. {What is a unit test?} : {A unit test automatically verifies that one small component such as a function produces the expected result.}
    
96. {Why should you test AI-generated software manually?} : {Manual testing can reveal incorrect workflows, interface problems, and unexpected behavior that generated code or automated tests may miss.}
    
97. {Why should empty inputs be tested?} : {Empty inputs often expose missing validation and assumptions that values will always exist.}
    
98. {Why should invalid inputs be tested?} : {Invalid inputs reveal whether an application handles mistakes safely instead of crashing or producing corrupted data.}
    

## Section 13 — Security

99. {What is authentication?} : {Authentication verifies the identity of a user attempting to access an application.}
    
100. {What is authorization?} : {Authorization determines which resources or actions an authenticated user is allowed to access.}
    
101. {Why should passwords never be stored as plain text?} : {Passwords should be securely hashed because plain-text storage exposes every password if the database is compromised.}
    
102. {What is SQL injection?} : {SQL injection is an attack in which malicious input manipulates a database query to access or modify unauthorized information.}
    
103. {What is input sanitization?} : {Input sanitization removes or handles potentially dangerous input before it is processed by an application.}
    
104. {What is the principle of least privilege?} : {The principle of least privilege means giving users and programs only the permissions they actually need.}
    

## Section 14 — Deployment & Hosting

105. {What does deploying an application mean?} : {Deploying an application means making it available in an environment where users can actually access and use it.}
    
106. {What is hosting?} : {Hosting provides the computing infrastructure on which a website, application, database, or service runs.}
    
107. {Why can an application work locally but fail after deployment?} : {Local and production environments may differ in dependencies, configuration, operating systems, environment variables, or network access.}
    
108. {What is a domain name?} : {A domain name is a human-readable internet address associated with a website or online service.}
    
109. {What is HTTPS?} : {HTTPS encrypts communication between a user's device and a web server to protect transmitted information.}
    

## Section 15 — AI-Assisted Coding Skills

110. {What is problem decomposition?} : {Problem decomposition means dividing a large software problem into smaller tasks that can be designed, implemented, and tested separately.}
    
111. {Why is problem decomposition essential for vibe coding?} : {AI usually produces more reliable code when it receives one clearly defined and manageable task at a time.}
    
112. {What makes a good coding prompt?} : {A good coding prompt clearly describes the goal, existing system, inputs, outputs, constraints, expected behavior, and relevant technical environment.}
    
113. {Why should you tell AI what technologies your project already uses?} : {Providing the existing technology stack prevents AI from introducing unnecessary or incompatible frameworks and libraries.}
    
114. {Why should you provide the exact error instead of saying "it doesn't work"?} : {The exact error gives AI evidence about the source of the problem and greatly improves its ability to diagnose it.}
    
115. {Why should large AI-generated changes be avoided when possible?} : {Smaller changes are easier to inspect, test, understand, and reverse when something goes wrong.}
    
116. {Why should you ask AI to explain its proposed changes before applying them?} : {An explanation helps you verify that the proposed solution matches the actual problem before modifying the project.}
    
117. {What should you do before asking AI to add a major feature?} : {You should define what the feature should do, how users interact with it, what data it needs, and how success will be tested.}
    
118. {What is refactoring?} : {Refactoring improves the internal structure of code without intentionally changing its external behavior.}
    
119. {Why is code simplicity valuable when vibe coding?} : {Simple code is easier for both humans and AI to understand, modify, test, and debug correctly.}
    
120. {What is the most important technical ability of a good vibe coder?} : {The most important technical ability is being able to understand, test, debug, and control AI-generated software rather than simply generating code.}
